# NEXUX FILMES V3

## O que há de novo
- Login/cadastro
- Admin
- SQLite
- Favoritos
- Player
- Trailer
- Carrosséis
- Filmes e séries
- **Gerenciador visual de temporadas**
- **Gerenciador visual de episódios**
- Criar/editar/excluir temporadas
- Criar/editar/excluir episódios
- Thumbnail por episódio
- Descrição e duração por episódio
- Link individual por episódio
- Cadastro/edição/exclusão de filmes e séries
- Destaques na home

## Rodar

```bash
npm install
npm start
```

Abra http://localhost:3000

## Admin padrão

E-mail: `admin@nexuxfilmes.com`
Senha: `Nexux@123`

Troque antes de publicar usando:
`ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET`.

## Render

Use um serviço Node e um disco persistente para a pasta `data/`, ou migre para PostgreSQL. O SQLite fica em `data/nexux.db`.
